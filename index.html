一、核心作品集架构（STAR 实测复盘）

1. 基于 Dify 与 RAG 的多源工单智能解析与跨系统数据搬运机器人
针对财务与客服跨 3 个系统核对录单日均耗时 3 小时的痛点，构建 Chroma 本地规则知识库与五要素 JSON Schema 约束 Prompt，结合 Redis 语义缓存与单号幂等校验，实现日均 220 条工单自动核验与回写，准确率 99.5%。
2. 融合双路视觉识别（OpenCV 模板匹配 + Umi-OCR）的智能巡检系统
摒弃写死绝对坐标做法，先用 OpenCV 模板匹配在 20ms 内锚定表头计算局部 ROI 区域，再结合动态滚动查找与 Umi-OCR 提取告警文本（置信度阈值 0.88），通过 Function Calling 路由大模型判定故障等级，识别率从 82% 提升至 97.4%。
3. 7×24 小时无人值守定时知识库同步与异常兜底调度体系
采用左闭右开时间区间判断自动避让凌晨 [02:00, 04:00) 停机维护窗口，内置端口探测、3 次指数退避重试、失败现场截图与企业微信 Webhook 告警，日均向量化同步文档 150 份，连续 30+ 天零漏跑。
