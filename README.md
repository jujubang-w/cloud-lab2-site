# 云端实验室

云计算与分布式系统实验二的静态展示页，使用原生 HTML、CSS 和少量 JavaScript，不需要安装依赖或构建工具。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 发布到 GitHub Pages

1. 将此目录中的文件上传到一个 GitHub 仓库。
2. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 将发布分支设为 `main`，目录设为 `/(root)`，保存并等待 Actions 部署完成。
4. 访问 `https://<用户名>.github.io/<仓库名>/`。

公开 Pages 站点可被任何持有链接的人访问。发布前不要在仓库中放置密钥、口令或个人隐私。
